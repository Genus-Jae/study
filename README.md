# Study

부트캠프에서 학습한 내용을 정리한 저장소입니다.

## 구성

- `python_basic`: 파이썬 기본 문법 실습
- `data_analysis`: 캐글 데이터셋(타이타닉 등) 기반 데이터 분석 튜토리얼 실습
- `database`: SQL/DB 관련 학습 및 실습
- `ML`: 머신러닝 학습 및 실습(캐글 데이터셋(타이타닉 등) 기반)
- `DL`: 딥러닝 학습 및 실습(캐글 데이터셋(타이타닉 등) 기반)
- `NLP`: 자연어처리 학습 및 실습
- `web_crawling`: 웹 크롤링 학습 및 실습

## 참고
